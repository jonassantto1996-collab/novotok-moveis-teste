# Novotok Móveis — Protótipo

Protótipo conceitual para um site de móveis planejados com foco em arquitetura, interiores e geração de leads.

## Stack
- Next.js 14
- React 18
- TypeScript
- CSS responsivo

## Rodar localmente
```bash
npm install
npm run dev
```
